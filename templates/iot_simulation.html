🔄 How The IoT Data Flows

📎

Wokwi ESP32 (virtual) 🔑 reads/simulates: soil moisture, temperature, humidity, rainfall

HTTP POST → sends JSON to: POST /api/sensor-data

Flask backend → validates values → saves to SQLite (new record every update)

Decision logic → irrigation decision + drought/heat risk + farmer recommendation

Dashboard / this page → shows the analysis with live connection status
